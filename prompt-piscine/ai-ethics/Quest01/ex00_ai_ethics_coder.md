# Part B: The Wrong Way vs. The Right Way

## 1 Write pseudocode for a palindrome check
``` python
1. function palindrome_check and take a parameter which is a string.
2. Normalizes the string 
3. Initailises two pointers, left = 0 and right = lenght - 1
4. compare the string from both ends
5. Then, return False if the character at left is not equal to the right.
6. And return True, if there is no mismatch.

```
## Implement your solution in Python
```python

def palindrome_check(s):
    left = 0
    right = len(s) - 1

    while left < right:
        if s[left] != s[right]:
            return False

        left += 1
        right -= 1
    return True

examples = ["racecar", "hello", "A man a plan a canal panama"]
for word in examples:
    result = palindrome_check(word)
    print(f"'{word}  {result}'")

```
