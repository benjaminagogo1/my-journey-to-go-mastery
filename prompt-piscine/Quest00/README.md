# ethical-ai

# A short summary of what you learned about AI and self-reliance

I have learned that AI can be a powerful learning tool that can enhance or aid the learning process as it saves time and increases speed, but not to replace critrical thinking or skip learning. True growth comes from self-reliance; when one is able to understand why and how things work, able to think through problems and make a good judgement about them. AI can be a useful learning amplifier to augment human thinking.


# Your main insight about using AI ethically as a coder.

Using AI ethically as a coder can be very helpful when it is used with conscience. That is, not to use as a code generator, but as an assistant to get deeper understanding and different approaches to novel challenges. Ultimately, it is how we use it that matters.

# One paragraph describing how you plan to apply these principles in future.

Personally, I plan to use AI as a learning assistant to enhance my problem-solving skills, get deeper insight of new challenges and broaden my understanding of problems, and logics behind challenges.
